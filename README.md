# templates — house coding standard bootstrap

The home of the house coding standard. A new repo adopts it by pasting the
block below into its README or AGENTS.md, replacing `<link>` with a link
from the dropdown. The block itself never changes — only the link list grows
as more files are added.

## Copy-paste

```markdown
Read this file first: <link>
```
